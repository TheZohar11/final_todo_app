# todoReact — Documentation

A React todo app (Vite) working against the Express/MongoDB server. The docs are split by subject under [docs/](./docs/) — each file is self-contained and ordered the way you'd build the feature.

## Contents

2. [Components, Props and State](./docs/components-and-state.md) — reusable components, controlled inputs, `useState`, layout/styling
3. [Making HTTP Calls](./docs/http-calls.md) — the validate → send → parse → act pattern, async/await, error handling
4. [Working with Server Data](./docs/server-data.md) — fetching on mount with `useEffect`, rendering lists of objects, POSTing new items
5. [Auth and localStorage](./docs/auth-and-localstorage.md) — the token lifecycle, protected requests, route protection
